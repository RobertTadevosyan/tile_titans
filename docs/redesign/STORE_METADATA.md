# Store metadata — Tile Titans

Written for whoever fills in App Store Connect and Play Console.

**Rule applied throughout:** every claim below describes something actually
implemented in the build. Nothing here advertises a feature that does not exist.
The previous listing leaned on "2048" as the hook, which is precisely the
positioning that invites a 4.3(a) comparison; none of these fields use it as a
selling point.

---

## App Store

**Title** (30 max)
```
Tile Titans: Merge Trials
```
28 characters. "Trials" carries the differentiator into the title itself.

**Subtitle** (30 max)
```
Daily puzzles, 4 game modes
```
27 characters. Two concrete, verifiable facts.

**Promotional text** (170 max, changeable without review)
```
A new Titan Trial every day — same puzzle for every player. Plus 18 hand-built
challenges, four rule sets that genuinely play differently, and per-mode ranks.
```

**Keywords** (100 chars, comma-separated, no spaces)
```
merge,puzzle,trials,daily,challenge,strategy,brain,tiles,numbers,logic,offline,ranks
```
Deliberately omits "2048". It is the obvious keyword and it is also the one that
files the app into the category the rejection came from. The game ranks for
merge/puzzle intent without inviting that comparison.

**Description**
```
Tile Titans is a merging puzzle built around designed challenges, not an endless
board.

TITAN TRIALS
18 hand-built puzzles across three chapters. Each starts from a fixed position
with a specific objective and a real constraint: a move budget, a clock, blocked
cells, or no undo. One of them spawns no tiles at all — a pure puzzle with an
exact solution.

DAILY TITAN TRIAL
A new challenge every day, generated from the date, so every player in the world
gets the same board and the same objective. Build a streak.

FOUR WAYS TO PLAY
Classic — the strategic baseline.
Zen — no score, and no game over. A stuck board clears its smallest tiles so you
can keep going as long as you like.
Time Attack — ninety seconds, but every merge buys you more. Chain them.
Hardcore — a bigger board, two tiles per move, mostly fours, and no help at all.

CLIMB THE PATH OF THE TITANS
Fifteen achievements carry you from Novice to Legend. Rank comes from what you
achieve — there is no currency and nothing to buy.

TRACK EVERYTHING
Records are kept per mode, because a Hardcore run and a Time Attack run are not
the same game. Separate leaderboards for each.

MADE TO LOOK AT
Every tile carries its Titan rank sigil. Six themes, from Classic through Forge.
Plays offline. Free.
```

**What's New**
```
Tile Titans is rebuilt around designed challenges.

• 18 hand-built Titan Trials across three chapters
• A Daily Titan Trial — same puzzle for everyone, every day
• Four rule sets that genuinely play differently
• Per-mode records, ranks and leaderboards
• Titan rank sigils on every tile, and a new Forge theme
• Fixed: a bug that could overwrite your leaderboard score with your current run
```

## What not to write

- Do not use "2048" in the title, subtitle or keywords.
- Do not say "best", "addictive" or "#1" — unverifiable and generic.
- Do not advertise Game Center, cloud save or multiplayer. None are implemented.
- Do not claim "new" mechanics beyond those listed; every line above maps to
  shipped code.
